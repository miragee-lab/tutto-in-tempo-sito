Sito di presentazione della versione corrente 1.0.0, aggiornato il 14 ottobre 2026.

Descrive categorie, avvisi principali e aggiuntivi con formato 24 ore, ricorrenze, profili guidati riprendibili, calendario, spese, condivisioni tramite file, documenti, backup, cloud personale ed email facoltativi gratuiti. Pubblicità, Premium, condivisione cloud tra utenti e OCR sono indicati come non attivi. Non contiene link a store ancora non pubblicati.

Il nome editore Miragee e il contatto info@miragee.it sono quelli confermati dall’utente. La privacy distingue il sito statico dall’app, identifica Supabase (database Irlanda) e Aruba Business, spiega consenso email e cancellazione delle copie dei dispositivi aggiornati, compresi i limiti offline e i file esportati. Nessun archivio personale, APK o credenziale è pubblicato.

Grafica blu petrolio coerente con l’app. Foto categorie già approvate, ottimizzate per il sito; screenshot reale dell’interfaccia corrente con archivio sintetico isolato. Font e licenze locali. Nessun cookie, script di analisi, modulo o risorsa incorporata da terzi.

GitHub Pages pubblica la radice di main con .nojekyll. Eseguire git pull --ff-only prima delle modifiche e pubblicare senza force push. Verificare contenuti, link, immagini, FAQ, layout desktop/tablet/mobile e URL pubblici dopo il push.
